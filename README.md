# 中国移动活动邀请落地页

这是一个移动端优先的静态落地页，用于在用户主动点击后跳转到中国移动官方活动链接。

## 本地预览

直接双击 `index.html`，或使用任意静态文件服务器打开。

## 发布

将 `index.html` 上传到支持 HTTPS 的静态网站空间即可。建议：

- 使用你本人可管理的域名；
- 必须启用 HTTPS；
- 不添加收集手机号、验证码或登录信息的表单；
- 不将页面包装成中国移动官方网站；
- 若官方邀请链接发生变化，应同步替换 `index.html` 中 `id="joinButton"` 的 `href`；
- 发布前用手机实际测试一次完整跳转流程。

## 当前跳转目标

页面会跳转到 `wap.ha.10086.cn` 下的官方登录中转页，嵌套活动地址指向同域名下的 `recommendGift` 页面。活动资格、权益和期限均以官方页面为准。
